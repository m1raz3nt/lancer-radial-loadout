# Lancer Radial Loadout

Модуль для [Foundry VTT](https://foundryvtt.com/) и системы **[LANCER](https://foundryvtt.com/packages/lancer)**.

Нажатие колеса мыши на токене раскрывает вокруг него радиальные слоты. В них назначаются оружие, системы и таланты, и активируются одним кликом — без открытия листа персонажа.

## Возможности

- Меню вызывается **нажатием колеса мыши** на токене и закрывается повторным нажатием. Вокруг токена — «безопасная зона»: пока курсор в ней, кружки не пропадают, а уход за её пределы сворачивает меню сам. Зона не перехватывает клики, соседние токены остаются доступны.
- Активация идёт через штатный **Lancer Flow API**, то есть с обычной автоматикой системы — нагрев, списание Limited, экономика действий.
- **Цвет каждого слота** выбирается отдельно: стандартный, красный, зелёный, синий, розовый, серый.
- Бейдж «текущее/максимум» для предметов с тегом Limited; сломанные и исчерпанные подсвечиваются отдельно.
- Радиус раскладки подстраивается под размер токена, поэтому на крупных мехах кружки не ложатся поверх модельки.
- В слот кладутся и **таланты**. На токене меха предлагаются таланты связанного пилота — в LANCER они принадлежат ему, а не машине.
- Если у предмета несколько действий, слот **не срабатывает, а разворачивается** своим веером: у Black Thumb второго ранга это отдельно спешивание и отдельно посадка обратно. Открытые ранги таланта система считает сама, так что веер растёт вместе с прокачкой.
- Шесть слотов под свои предметы плюс **хаб базовых действий** сверху: наводишь на него — и он рассыпается веером на импровизированную атаку, перегрузку, стабилизацию, проверку структуры и перегрева, тех-атаку, скан и остальное. Эти действия зашиты в веер и не расходуют слоты.
- Интерфейс переведён на русский и английский, язык берётся из настроек Foundry.

## Управление

| Действие | Что делает |
|---|---|
| **Колесо мыши** по токену | Открыть радиальное меню; повторное нажатие закрывает |
| **Наведение** на хаб сверху | Веер базовых действий; клик по нему тоже разворачивает |
| **ЛКМ** по кружку веера | Соответствующий флоу системы |
| **ЛКМ** по слоту | Активация. Оружие → бросок атаки, одно действие → это действие, иначе карточка предмета |
| **Наведение** на слот с пунктирным ободком | Веер действий этого предмета |
| **ПКМ** по слоту | Назначить/сменить предмет и выбрать цвет слота |
| **ЛКМ** по пустому слоту | То же окно назначения |
| **Shift+ЛКМ** | Счётчик Limited −1 (без броска) |
| **Shift+ПКМ** | Счётчик Limited +1 (без броска) |

Какие предметы можно класть в слот: `mech_weapon`, `mech_system`, `npc_feature`, `pilot_weapon`, `pilot_gear`, `talent`. Базовые действия в слоты не назначаются — они живут только в веере; их набор задан в `BUILTIN_ACTIONS` (`scripts/constants.js`) и фильтруется по типу актёра, так что перегрузку пилот не увидит.

## Кто видит слоты

Игрок видит радиаль на токенах, которыми владеет. Для меха засчитывается и **Owner на связанном пилоте** — в LANCER это разные актёры с раздельными правами.

GM по умолчанию видит слоты только там, где актёром управляет какой-нибудь игрок; настройка `gmSeesAll` снимает ограничение.

## Установка

В Foundry: **Add-on Modules → Install Module** → вставить manifest URL:

```
https://raw.githubusercontent.com/m1raz3nt/lancer-radial-loadout/refs/heads/main/module.json
```

## Настройки модуля

*Configure Settings → Module Settings → Lancer Radial Loadout*:

| Настройка | Область | По умолчанию | Что делает |
|---|---|---|---|
| GM видит кружки на всех актёрах (`gmSeesAll`) | world | выкл | Выкл: GM видит слоты только там, где актёром управляет игрок. Вкл: на всех мехах/NPC/пилотах |
| Показывать счётчик расходов (`showUses`) | world | вкл | Бейдж «текущее/максимум» для предметов с тегом Limited |
| Подсвечивать безопасную зону (`showSafeZone`) | client | выкл | Едва заметное кольцо вокруг токена, в котором кружки не пропадают |

Геометрия задаётся константами в `scripts/constants.js`: `SLOT_COUNT` (число слотов), `RADIUS` (минимальный радиус), `SAFE_PAD` (насколько зона шире кружков), `HIDE_DELAY`, а для веера — `FAN_GAP` (насколько он дальше кольца), `FAN_SPREAD` (дуга) и `FAN_DELAY` (он вдвое длиннее `HIDE_DELAY`: кружки веера мельче и дальше, промахнуться легче). Слоты раскладываются со сдвигом на полшага, чтобы верх кольца остался под хаб. Палитра — объект `SLOT_COLORS` там же: добавить цвет значит дописать в него строку.

## Совместимость

Foundry **v13**, система `lancer`.
